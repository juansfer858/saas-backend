Local + nube

Tu sede no debería depender de una pestaña conectada a Internet para cada operación.

VantixGC Edge funciona como runtime local de la sede. Los equipos del restaurante trabajan por la red local y VantixGC Cloud centraliza configuración, respaldo, usuarios, sincronización y acceso remoto.

Cuando se cae Internet, la operación interna preparada para Edge continúa localmente y se sincroniza al recuperar conexión.

Preguntas frecuentes

Antes de empezar.

Lo esencial sobre la prueba, instalación y operación.

¿Tengo que instalar algo para ver VantixGC?

No. Puedes abrir el demo interactivo directamente en el navegador. La instalación de Edge se hace cuando quieres probar la operación local de una sede.

¿La prueba de 14 días pide tarjeta?

No. El alta actual inicia en modo de prueba sin tarjeta. La capa de cobro recurrente se integra por separado cuando se habiliten los planes comerciales.

¿Cuántos computadores debo instalar?

La arquitectura prevista es un Edge principal por sede. Caja, KDS y otros equipos de esa misma sede se conectan por LAN al Edge.

¿Qué pasa si se cae Internet?

Las capacidades internas preparadas para Edge continúan contra el runtime local y sincronizan con el Core cuando regresa Internet. Los servicios que por naturaleza dependen de la nube o de terceros requieren conectividad.

¿VantixGC es solamente para restaurantes?

No. Restaurante es un vertical de VantixGC. El Core y Edge son universales y están diseñados para soportar otros nichos mediante verticales independientes.
