Preguntas frecuentes

Antes de empezar.

Lo esencial sobre la prueba, la membresía y la operación.

¿La prueba de 14 días pide tarjeta?

No. Puedes crear el restaurante y comenzar la prueba sin registrar una tarjeta.

¿Me cobran automáticamente cuando terminan los 14 días?

No. La prueba no genera un cobro automático. Antes de activar una membresía comercial se informa el valor y las condiciones para que decidas si continúas.

¿Tengo que instalar algo para ver VantixGC?

No. Puedes usar el demo interactivo directamente en el navegador. Edge se instala cuando quieres probar la operación local de una sede.

¿Qué incluye la membresía Restaurante?

La propuesta integra la operación principal: Mesas, Pedidos, Producción/KDS, División, Caja, Domicilios, Carta, usuarios, roles y la arquitectura local + nube. La definición comercial final puede evolucionar antes de habilitar cobro recurrente.

¿Qué pasa si se cae Internet?

Las capacidades preparadas para Edge continúan contra el runtime local y sincronizan con el Core cuando regresa Internet. Los servicios externos que requieren nube siguen necesitando conectividad.
