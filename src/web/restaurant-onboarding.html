4. Instalar VantixGC en esta sede

Este es el paso que instala el sistema local en Windows. Generar o descargar el archivo por sí solo no instala nada.

  • Genera y descarga el instalador.
    El navegador guardará INSTALAR_VANTIXGC_RESTAURANTES.cmd.
  • Abre el archivo descargado.
    Si Windows pide permiso de administrador, elige Sí.
  • Deja terminar la instalación.
    VantixGC instala Edge Universal, SQLite, Supervisor de Windows, LAN y el acceso directo.
  • Espera la confirmación ONLINE.
    Esta pantalla detectará automáticamente cuando la sede realmente esté instalada.
