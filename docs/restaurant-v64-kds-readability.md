# Restaurante V64 — legibilidad de comandas

V64 ajusta únicamente la presentación de `/app/produccion`.

- El nombre del operador/mesero deja de mostrarse en las tarjetas del KDS.
- Se conserva la antigüedad de la comanda (`ahora`, `N min`, etc.).
- El nombre del producto aumenta a 18 px y mantiene peso alto para lectura rápida a distancia.
- Las notas de producto permanecen visibles y separadas.
- No cambian estados, permisos, vinculación de tablet, pedidos, impresión, Caja, inventario, contabilidad ni DIAN.
