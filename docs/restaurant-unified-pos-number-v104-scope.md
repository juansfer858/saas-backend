# Scope V104

Cambio limitado al consecutivo interno POS de Restaurante.

Incluye:
- Ventas de mesa `REST-TABLE-*`.
- Ventas de domicilio `REST-DELIVERY-*`.

No incluye:
- Renumeración de documentos históricos.
- Cambios en Caja, División, pagos, Inventario, Tesorería, Contabilidad o Edge.
- Cambios fiscales/DIAN.
